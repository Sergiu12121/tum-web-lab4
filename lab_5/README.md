# Lab 5 - Websockets

## Features

- Fetch a URL and display the response (`-u <URL>`).
- Search for a term using a search engine and display the top 10 results (`-s <search-term>`).
- Handle HTTP redirects.
- Implement an HTTP cache mechanism to avoid redundant requests.
- Support content negotiation for JSON and HTML responses.

## Usage

### Fetch a URL

```bash
src/go2web -u https://999.md/ro/88603152
```
